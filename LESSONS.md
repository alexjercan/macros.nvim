# Lessons

Durable, general lessons distilled from task retros. One entry per lesson:
slug, one sentence, a bare occurrence count, and the tasks it came from. An
entry that reaches three occurrences moves to Pending promotions.

## Lessons

- `absence-claims-are-repo-wide` - a "no X exists here" claim in a plan is made
  from a repo-wide search or not at all; a per-directory grep found no version
  constant while two sat at the repo root. 1 - 20260731-144835
- `lint-the-ci-you-build-on` - when the deliverable is CI, run the CI linter
  over the existing workflows during planning; deprecated action pins broke the
  gate the new release flow depended on. 1 - 20260731-144835
